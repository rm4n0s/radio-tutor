# Υλικά σώματα: the narration script

The narration of the four lessons of `examples/cassettes/fysika-e-01-ylika-somata`, in the order it is spoken. Every sentence is also the caption shown at that time.

- Voice: [piper](https://github.com/rhasspy/piper) with `el_GR-rapunzelina-low` (a little slower than normal: `length_scale` 1.1), one sentence at a time, joined with the pauses of `script.json`.
- The times below are what the current recording measured (seconds from the start of the narration). The animation of each scene is tied to the sentences by anchors (`lessons/<id>.json`: `s3` is the start of sentence 3, `e3` its end), so the animation follows a new voice (check the result with `validate` and by watching the lessons: a key placed long after the start of a sentence may need adjusting).
- To record the narration again (another voice, or after changing a sentence), edit `script.json` and run from the repository root:

  ```
  python3 examples/cassettes/fysika-e-01-ylika-somata-src/narrate.py \
      examples/cassettes/fysika-e-01-ylika-somata-src examples/cassettes/fysika-e-01-ylika-somata \
      --piper ~/piper/bin/piper --model ~/piper/el_GR-rapunzelina-low.onnx
  go run ./cmd/radio-tutor validate examples/cassettes/fysika-e-01-ylika-somata
  go run ./cmd/radio-tutor pack --force examples/cassettes/fysika-e-01-ylika-somata examples/cassettes/fysika-e-01-ylika-somata.cassette
  ```
  It needs piper, `ffmpeg` and `ffprobe` (with libvorbis). Write numbers as words in the sentences. Changing the text of a sentence changes the cassette: raise the version in `cassette.json` and keep every id.
